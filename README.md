# Muhammad Usama — IoT & Embedded Systems Portfolio

Personal portfolio site: firmware, sensor drivers and connected-device projects (ESP32/ESP8266, Arduino, C, Python).

Live: https://usamamugha-l.github.io/github-repository/

## Stack
Plain HTML, CSS and JavaScript. No build step.
- [AOS](https://github.com/michalsnik/aos) 2.3.4 for scroll animations (loaded from unpkg; the page still works if it fails to load)
- Fira Code from Google Fonts

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Structure
```
index.html        page markup
style.css         styles (dark/light theme via CSS variables)
main.js           menu, theme toggle, scroll spy, cursor, certificate lightbox
src/webp/         optimised images used by the page
src/pdf/          resume
```
